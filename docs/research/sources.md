# Primary sources and design traceability

Accessed 2026-09-08. These are inputs to hypotheses; HKL results are reported separately. No paper is reproduced here. The workbench uses Python's standard library and the repository's `jsonschema>=4.23,<5`; actual installed versions appear in every run. JSON Schema and format checks follow the [jsonschema validation API](https://python-jsonschema.readthedocs.io/en/stable/validate/). Reference and decision checks are additional application rules.

| Source, exact title, date and type | Sections read, contribution and limits |
|---|---|
| Fabio Vitali and Valentina Pasqual. **Provenance-Enhanced Statements in Knowledge Graphs**. arXiv v1, 13 June 2026; preprint. [Landing page](https://arxiv.org/abs/2606.15246), [full text](https://arxiv.org/html/2606.15246v1). | Sections 2 and 4.1–4.3 distinguish correct attribution from factual commitment and isolate epistemic contexts. E1 hypothesizes that explicit attribution, derivation and scoped simulated acceptance prevent unsupported promotion. HKL does not implement DEC, modal logic or its factual core, and does not reproduce its reasoner results. |
| Oleksandra Bruns, Jörg Waitelonis, Jeff Z. Pan and Harald Sack. **Temporal Modelling in Cultural Heritage Knowledge Graphs: Use Cases, Requirements, Evaluation, and Decision Support**. 31 March 2026; journal article, *Transactions on Graph Data and Knowledge* 4(1), 2:1–2:46. [Publication](https://drops.dagstuhl.de/entities/document/10.4230/TGDK.4.1.2), [paper](https://drops.dagstuhl.de/storage/08tgdk/tgdk-vol004/tgdk-vol004-issue001/TGDK.4.1.2/TGDK.4.1.2.pdf). | Sections 2.1–2.2 and 3.2 cover changing descriptions, temporal scopes, uncertain dates and event models. Their comparison of six RDF approaches is context-dependent. E2 tests a Python assertion/interval projection, not those RDF engines. Recording time versus valid time is our concrete implementation hypothesis. |
| U.S. National Archives. **16363 Reasons to Trust**. 6 March 2025; institutional blog post. [Article](https://fixity-check.blogs.archives.gov/2025/03/06/16363-reasons-to-trust/). ISO. **ISO 14721:2025 — Space Data System Practices — Reference model for an open archival information system (OAIS)**. March 2025, edition 3; international standard. [Catalog and abstract](https://www.iso.org/standard/87471.html). | NARA's “Updated Methodology in 2025” motivates achievable preservation objectives and documented assessment. The ISO catalog confirms edition/date and describes preservation responsibilities. Only the public catalog/abstract was accessed, not the paid standard text. E3 defines three local recovery objectives; it is neither an ISO audit nor OAIS certification. |
| RO-Crate community. **RO-Crate Metadata Specification 1.2.0**. 4 June 2025; community specification/recommendation archived as a standard on Zenodo. [Versioned record](https://zenodo.org/records/13751027), [root entity](https://www.researchobject.org/ro-crate/specification/1.2/root-data-entity.html), [metadata](https://www.researchobject.org/ro-crate/specification/1.2/metadata.html), [provenance](https://www.researchobject.org/ro-crate/specification/1.2/provenance.html). | Read root/descriptor requirements and provenance sections on software, inputs/results, and curation actions. E3 connects Dataset, File, SoftwareApplication and CreateAction/UpdateAction descriptions. Version 1.2 is deliberately pinned although the site now advertises 1.3. The local checker implements an enumerated subset, not general JSON-LD or full RO-Crate conformance. |
| Achille Felicetti, Aida Himmiche and Miriana Somenzi. **Knowledge Graphs and Artificial Intelligence for the Implementation of Cognitive Heritage Digital Twins**. 15 September 2025; *Applied Sciences* 15(18), 10061. [Published DOI](https://doi.org/10.3390/app151810061), [accessible manuscript v1](https://www.preprints.org/manuscript/202507.1673). | Direct publisher access returned an error; its indexed primary page confirmed publication metadata. The accessible manuscript v1 was posted 21 July 2025 (submitted 19 July). Read that manuscript, particularly sections 3.4 and 4.1–4.2, which emphasize interpretive entity alignment and distinguish documentary, observation and digital-provenance roles through the CIDOC CRM ecosystem. E4 uses a conceptual crosswalk, not a claimed ontology implementation or replication of the paper's AI performance. Manuscript and journal versions must not be treated as textually identical. |
| Satyananda Kashyap, Niharika DSouza, Nandana Mihindukulasooriya and Horst Samulowitz. **How Much Structure Should Agentic Graph Memory Build for Text Retrieval?** 31 August 2026; VLDB workshop paper. [IBM publication](https://research.ibm.com/publications/how-much-structure-should-agentic-graph-memory-build-for-text-retrieval), [full paper](https://vldb.org/2026/Workshops/VLDB-Workshops-2026/Agents%2BGraphs/AgentGraph26-2.pdf). | Sections 4–6 explain the construction pipeline, fixed retrieval/reader comparison, evidence coverage and measured cost accounting. They report benefits from a lighter entity-centric construction in their tested systems. E5 borrows the experimental question and controls. HKL uses manual fictional annotations, lexical scoring and deterministic rendering, so it cannot compare performance with their LLM systems. |

## Verified starting point

Baseline commit: `e5391af4905f1c615e1b34c51692b02fd817cb21`. [Baseline CI succeeded](https://github.com/RichardRacette/household-knowledge-language/actions/runs/31185061951). No open PRs or repository/parent AGENTS.md instructions were found at inspection. `baseline.json` records seven passing tests, three passing example validations, the initial missing-dependency failure and the local Python 3.14.7 environment. Existing CI targets Python 3.12.

The original validator calls Draft202012Validator with FormatChecker. It checks types, enums, required fields and formats. It contains no reference resolution, approval authentication, source entailment, privacy filtering or temporal interval semantics. The original tests cover seven schema behaviors. “Governance” in the original prose is not executable semantic enforcement.
