# Experimental contract v1

Frozen before retrieval implementation or tuning, 2026-09-08. All data are independently fictional or derived solely from the three public examples. Every decision is a simulation. This contract governs the public workbench only.

## Inputs and revision policy

Twelve records build on the public Marlow bird, Calder display and Hartwell collection. A separate experimental profile supplies qualified identities, typed assertions, derivations, visibility, simulated decisions and temporal projections. Root examples and their schema remain compatible. Original examples are retained as earlier versions. Synthetic text files are real bytes representing authored source descriptions; they are not recovered historical photographs or interviews.

`research/fixtures/v1/manifest.json` freezes SHA-256 hashes of corpus, profile, source bytes, 24 questions, gold evidence and structured outcomes. Runners verify the manifest before experiments. Gold lives only in the evaluator. Eighteen development and six final alternate-entity/paraphrased questions are fixed before construction. The holdout is an engineering split visible to the author, not a blinded independent evaluation. Fixture changes require a new version and an explicit reason in revisions.md; failures never justify silently changing gold.

## Shared layers and controls

1. Legacy JSON Schema validates record structure/formats; experimental schema validates envelope structure.
2. Semantic checks resolve references, uniqueness, derivation, types, intervals and simulated decisions. No natural-language entailment or identity authentication is claimed.
3. Answer eligibility uses only retrieved public evidence and structured assertions. It preserves attribution, epistemic state, derivations and decision references. Unknown, Qualified, Private and Needs Human are legitimate results.
4. Retrieval evaluates frozen supporting evidence and answer plans. All three modes use identical source units, pre-index visibility filtering, budget of four evidence units, and a deterministic reader/renderer. No model, token estimate, prepared Q&A, gold answer, question text or expected evidence enters an index. Query text and a caller-supplied structured intent are available identically to every mode and the reader. This tests retrieval and structured planning, not language understanding.

## Tracks

## Execution and publication

Every run records UTC time, exact commands, Python/dependency versions, full Git revision, dirty state and code/schema/profile/fixture hashes. Generated results are evidence for that revision and those bytes, not later implementation. A report-only commit may publish them. CI discovers all unittest suites and retains validation of all original examples. Negative research outcomes stay in results. Each recommendation is ADOPT IN PUBLIC WORKBENCH, REVISE or DEFER with explicit scope.
